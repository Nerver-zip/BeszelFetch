# AGENTS.md

## Repository Mission

Build and maintain a homelab monitoring KWGT widget directly consuming the Beszel API, featuring a Linux/Unix ricing aesthetic and Catppuccin Mocha palette.

## Architectural Constraints

1. Do not introduce any additional backend, proxy, or bridge without explicit user request.
2. KWGT/Kustom is the sole client.
3. Beszel Hub / PocketBase is the sole data source.
4. Secrets must never enter fixtures, screenshots, or git commits.
5. Raw API and UI must remain decoupled via an adapter layer.
6. Network failure must never wipe or corrupt the last valid cache.
7. Default refresh intervals must remain conservative.
8. The exported preset must be generated by KWGT itself.

## Definition of Done

A change is only complete when:
- It adheres to the direct client-to-hub architecture;
- It functions reliably with local caching;
- It provides graceful fallbacks for errors or stale data;
- It leaks no secrets or credentials;
- It preserves touch target accessibility and legibility;
- It updates documentation/fixtures whenever API contracts change;
- It has been validated under at least one relevant failure scenario.
