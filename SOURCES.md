## Documentation Precedence Policy

As both Beszel and Kustom evolve, live probe payloads and documentation of the specific installed versions take precedence over static examples in this repository.

Verify live contracts whenever:
- An endpoint path changes;
- Flow UI configuration changes across Kustom releases;
- A compact payload key is added, modified, or deprecated;
- PocketBase collection rules are updated.
